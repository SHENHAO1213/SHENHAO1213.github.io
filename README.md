# Hao Shen — personal research website starter

This is a lightweight static-site MVP. No framework or build step is required.

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages** and publish from the main branch/root if needed.
4. Your site will appear at `https://YOURUSERNAME.github.io`.
